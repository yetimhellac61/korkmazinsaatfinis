# Korkmaz Yapı | İnşaat & Taahhüt Portalı

Korkmaz Yapı'nın tamamlanan ve sergilenen prestijli konut/rezidans projelerini tanıtan, modern, minimalist ve yüksek performanslı kurumsal web portalı.

---

## 🏗️ Proje Özellikleri

- **Modern & Premium Tasarım:** Syne ve Inter yazı tipleri, derin antrasit tonları ve altın/bronz vurgularla lüks inşaat teması.
- **Kompakt Medya Modalı:** Projelere tıklandığında açılan, sol tarafında otomatik döngüde oynayan sessiz kare GIF animasyonu, sağ tarafında ise detaylı teknik verileri içeren tablo yapısı.
- **Dinamik Proje Filtreleme:** Tamamlanan projeleri listeleyen ve asenkron zamanlayıcı yarış durumları (race conditions) çözülmüş dinamik JavaScript filtreleme sistemi.
- **Yönetim Kurulu Üyeleri:** Şirket ortaklarının kurumsal portrelerini ve ünvanlarını içeren özel responsive ızgara alanı.
- **Teklif İsteme & İletişim Formu:** Ziyaretçilerin doğrudan hizmet grubu seçerek detaylı bilgi ve lansman fiyatı isteyebileceği etkileşimli form yapısı.

---

## 📁 Klasör Yapısı

Proje dosyaları GitHub standartlarına ve temiz kod prensiplerine uygun olarak organize edilmiştir:
- `/` (Kök Dizin): `index.html` (Giriş noktası), `README.md` ve `.gitignore`
- `/img`: Logolar ve Yönetim Kurulu Başkanlarının kurumsal JPG görselleri.
- `/videos`: Projelerin şantiye animasyonları (optimize edilmiş ve hafifletilmiş 10 saniyelik GIF formatında).

---

## 🛠️ Nasıl Çalıştırılır?

Bu proje bağımsız bir statik web sitesidir. Çalıştırmak için kök dizindeki `index.html` dosyasını herhangi bir web tarayıcısında (Chrome, Edge, Safari vb.) açmanız yeterlidir.

Alternatif olarak, geliştirme ortamında çalıştırmak için:
```bash
# Live Server (VS Code) veya herhangi bir yerel HTTP sunucusu ile başlatın
npx serve .
```
